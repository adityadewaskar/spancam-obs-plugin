Installed

  1. Quit OBS Studio completely and open it again. OBS only looks for new plugins while it starts, so a running copy will not see this yet.
  2. Go to Sources → + → Spancam Camera.
  3. Pick your phone from the Phone dropdown. If the list is empty, the source itself shows a QR code that installs the phone app.

Help and downloads: adewaskar.com/apps/spancam/obs
